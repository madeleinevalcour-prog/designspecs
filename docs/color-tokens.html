Four core semantic color tokens for text, surface, and accent. Use the semantic token, not the resolved value — the token is the contract, the hex behind it can change.

These tokens name intent, not color. color/text/primary means “the primary reading text on a surface” wherever it is used, so a theme or palette change updates every consumer at once. Reference the token in design and code; treat the resolved hex as an implementation detail.

Resolved values were not read from the source of truth — the live Figma variable connection is unavailable in this environment. Only color/accent/primary has a known value, and it is a raw hex pending rebind. The other three resolved values are shown as to be confirmed rather than guessed.

Primary reading text — body copy, headings, and default foreground on a surface. Supporting text — descriptions, secondary labels, and de-emphasized foreground. Raised surface — cards, menus, and panels that sit above the base background. Primary accent — key actions and emphasis.
