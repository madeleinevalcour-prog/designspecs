The Ace Homepage prototype makes Home the Amplify landing page. Clicking the Amplify tab or the “Amplify” breadcrumb opens Home instead of a new chat. It was split out of the V2 concept in the Amplify tab prototype.

What’s on Home

  • Greeting: the day, plus a one-line summary of today’s meetings and how many items need action.
  • Ask box: the Amplify chat input. Sending a message starts a new chat.
  • To do: items to act on, each with a checkbox and an action button. Completed items are hidden behind “Show completed”.
  • Suggested: prompts based on today’s records and meetings. Clicking one sends it to a new chat.
  • Need to know: updates from scheduled runs, each linking to its chat or schedule.
  • Today: the day’s meetings.

Chat, the Scheduled page and the Chats panel are the same as in the Amplify tab prototype, so Home’s links work.
