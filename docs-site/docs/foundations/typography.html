Typography is delivered as a set of composed text styles, each tied to a role. A text style bundles font family, size, weight, line height, letter spacing, and case into one named value. Components apply the style; they never set the underlying properties individually.

  • Primitives — the raw type values: font family, the font-size scale, the line-height scale, weights, and letter-spacing steps. Never apply a primitive directly.
  • Text styles — role-based compositions (title, body, input, button, and so on) built from the primitives. This is the layer components apply.

The system is organized by role, not by an abstract size scale. A style is chosen by what the text is (a card title, a field value, a button label), not by picking a size. This is what makes consistency hold across workflows — inconsistent, system-flavored UI is a named user pain, and it only holds when enforced in the system rather than left to per-screen judgment.

The entire system is set in Inter (typography/font-family/inter). There is no secondary or display face. A single typeface keeps dense, high-information surfaces consistent and calm — it removes a variable that would otherwise add visual noise, and restraint is what reads as current.

Inter

Regular 400 · Medium 500 · Semi Bold 600

Weight is fixed by role, not chosen situationally. Three weights are in use across every text style. Fixing weight to role means the same kind of text always looks the same, and it lets weight work as a reliable signal: because weight never varies for decoration, a shift to Medium reads unambiguously as a state or emphasis change.

Carrying selected state with weight rather than color alone keeps the state legible where color can't be relied on — never signal state with color alone (WCAG 2.2 AA). Apply the named text style, and choose it by role — use title/sm for a card title because it is a card title, not because 18px looks right. Set size, weight, or line height directly on a component, vary weight by situation, or reuse the uppercase-label 0.5 tracking outside labels. Pair input/value/hyperlinks with the link color so linked values read as links by both weight and color.
