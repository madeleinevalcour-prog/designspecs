A small round count of new items for the corner of a control. In the Amplify header it shows unread scheduled runs on the Chats button. It’s its own component so other controls can use it; to pin it to a button, use Button with count.
  • 16px tall, at least 16px wide (count-badge/spacing/size). One digit is a circle; longer counts stretch into a pill.
  • 4px left and right padding (count-badge/spacing/padding-horizontal), fully round (count-badge/border/radius/default).
  • A 2px ring outside the badge (count-badge/border/width/default, count-badge/color/border/default) separates it from the control underneath. It doesn’t change the badge’s size.
  • Number in text style meta/small (Inter Medium 10/12).
  • Shows the count up to 99, then “99+”.
  • At 0 it renders nothing. Never show “0”.
  • It isn’t a separate click target; it belongs to the control it sits on.
  • The badge is aria-hidden. Put the count in the control’s accessible name instead: “Chats, 2 new”.
  • White on the badge fill (#1450A0) passes 4.5:1.
