Filter—Search Input, pill, placeholder “Filter” (the bowling alley’s Menu uses “Filter Items”)
  • Typing in the Filter updates [(filter)]; the owner filters its list. In the bowling alley the Menu filters its apps by label.
  • Escape in the Filter and the close button both emit closed.
  • Add/Remove emits addRemove and Done emits done. In Figma, Add/Remove leads to the Edit Menu (menu-edit: menu-header plus inline checklists); that panel isn’t built yet.
  • All actions are native buttons; the close button is labelled “Close menu”.
  • The Filter is a native search input labelled by its placeholder. focusFilter() moves focus to it; the Menu calls it on open.
