A list item is one result row: an entity avatar and title, a wrapping row of meta fields, and an optional body line. Fast Find uses it for its results.
PartFigma nameNotes
Avataritem-avatar24px, color/entity/<type>, white 12px glyph
Titleitem-headertypography/body/lg medium, list-item/color/content/header
Fieldsitem-data12px icon + typography/input/value/sm; wraps with an 8 / 16px gap
Bodyitem-contenttypography/body/default, list-item/color/content/body

Fields and body are optional. Rows stack with a bottom border; the last row has none.
  • The row is a native button: the whole row is one control, reachable with Tab and activated with Enter or Space.
  • Field icons are decorative; the field text carries the meaning.
