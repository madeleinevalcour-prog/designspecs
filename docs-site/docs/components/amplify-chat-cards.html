A stack of record cards for replies where each record needs a reason it was picked, carries several values of one kind, or will be acted on one by one. Each card is built on the Modern UI list-item. The stack shares the table’s selection model and selection bar, and can page through more results in that bar.

When to use cards instead of a table, and how many, is set in Chat interface patterns. That page wins where the two differ.

  • Relevance signals belong to Prospect. Relevancy dots belong to candidate search. They never appear in the same reply.

 Use cards when each record needs a reason, several chips, or its own action. Use cards to compare records on the same short fields. When it’s unclear, use a table. Show 3 cards by default and 5 at most per page. Page the rest in the bar. Stack more than 5 cards in one view, or wrap the stack in an outer container. Rank by relevance and say how in the rationale line. Show one set of records as both cards and a table, or mix relevance signals and relevancy dots.
