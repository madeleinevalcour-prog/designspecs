A menu option is one row of a dropdown menu: an icon and a label. The bowling alley’s Add menu and user menu are built from it.
TypeIconUsed in
defaultA 16px glyph (Figma example: configure-outline)User menu (user-dropdown-panel 168:19961): Preferences, Logout
entityAn icon container, size sm. The label truncates with an ellipsisAdd menu (fast-add-menu 4711:42682)

The dropdown card around the rows (padding, border, shadow) belongs to the overlay; see Bowling Alley.
  • Each option is a native button; the label is its accessible name. The icon is decorative.
  • Keyboard focus shows a 2px inset ring (color/border/focus).
