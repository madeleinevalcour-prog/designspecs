Record Header sits at the top of a record’s Overview. It names the record, shows its key fields, and holds the record-level actions and section tabs.
RowWhat’s in it
1. ToolbarEntity avatar (48px, entity color), title, optional Verified chip and social-link icon buttons, then Copy link / Pin / Refresh icon buttons, a secondary Actions button and a primary amplify Amplify button
2. Field summaryLabel + value pairs that wrap onto more lines when they don’t fit
3. Tab rowSection tabs on the left; More and Layout dialogue buttons on the right

Both variants are the same component with different data. The entity sets the avatar glyph, the avatar color and the active-tab underline.

Each field has an uppercase label and one of four value kinds.

  • Click a tab to make it active. The active tab gets weight 500 and a 2px underline in the entity color.
  • Tabs that would run into More / Layout move into the More menu, last tab first. The active tab never moves. The split updates whenever the header resizes.
  • More opens a menu of the moved tabs. Pick one to make it active. Click outside or press Escape to close.
  • It’s a native <header>; the tabs sit in a <nav aria-label="Record sections">, and the active tab has aria-current="page".
  • Icon-only buttons have an aria-label: Copy link, Pin, Refresh, and the social-link icon name.
  • More has aria-haspopup="menu" and aria-expanded. Opening it moves focus to the first item; arrow keys move between items; Escape closes it and returns focus to More.

The component lives in the ats-ui Angular library, applied to a native <header>.

<header ats-record-header title="Nexus Dynamics" entity="company" [fields]="fields" [tabs]="tabs" verified [social]="['linkedin', 'location']" [(activeTab)]="tab" (action)="onAction($event)"></header>

The sticky-header elevation (and its 8px backdrop blur) has no elevation token yet, so the values are hardcoded. The green-to-blue tint is a raw 12% gradient of the amplify green and blue. There’s no token for it. Entity colors exist only as primitives (color/entity/*); there’s no semantic or header token. The header has 0 bottom padding and tabs use 4px horizontal padding, matching the prototype. The tokens say 16px (header/spacing/padding-bottom) and 8px (tabs/spacing/tab-items/padding-horizontal).
