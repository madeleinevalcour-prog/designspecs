The recruiter’s message in an Amplify conversation. A tonal bubble that hugs its text up to 440px, right-aligned in the chat column so the two sides of the conversation read apart at a glance. Long messages, such as a pasted job description, collapse to 8 lines with Show More.

The rules for user messages, and how they sit in the conversation, are in Chat interface patterns. That page wins where the two differ.

ComponentWhat it does
User bubbleThe message: body/default in color/text/body on color/background/subtle-hover, radius border/radius/sm (8). Hugs its content up to 440px, then wraps
User turnThe full-width row that right-aligns the bubble in the chat column

Three states. The bubble measures its message and picks the state itself; state only forces one for docs.

StateLook
user-bubble (default)The full message. Up to 8 lines, no control
long textOver 8 lines: capped at 8 lines (160px plus padding), the last 2 fade out through an alpha mask, and a Show More button (Button, Dialogue, Small) sits below. Fills the 440px max
long text expandedThe full message with Show Less
clarify answersThe answers to a clarifying-questions round, as label and answer rows. See Clarifying answers
  • The cap is set in lines, not pixels, so it follows the type scale.
  • The fade is a mask, not a color overlay, so the text keeps its token color on any bubble fill.
  • Line breaks in the message are kept. Several <p> children get spacing/padding/sm (8) between them.

When the recruiter finishes a clarifying-questions round, all the answers post as one message in the clarify answers state. Each row pairs the question’s short label with the answer, so the recruiter can see at a glance what Amplify is about to work from.

PartStyle
Question labelThe question’s short label (“Job order” for “Which job order?”), in an 80px column: input/label/field-label, color/text/subtle
AnswerThe message style: body/default, color/text/body, 16 after the label column
Record answerThe inline entity link, with the record’s entity color, so the chosen record looks the same as anywhere else in the conversation
RowsOne per question, spacing/4 apart. Up to 3, matching the 3-question cap
Give each clarifying question a short label for this message, such as “Job order”, “Location”, “Candidates”. Repeat the full question text in the rows, or post each answer as a separate message.

When the recruiter tags a record in their request, such as a job, company or candidate, it appears in the bubble as the same inline entity link Amplify uses in its replies: a circle in the entity’s color, then the record name in link color and medium weight. The link opens the record. Untagged words stay plain text.

Use the entity link from the Text components inside the bubble, so a record looks the same wherever it appears in the conversation.

The bubble doesn’t align itself. The user turn is a full-width row in the 800px chat column that pushes its bubble to the right edge. Turns are spacing/gap/xlg (32) apart; that spacing belongs to the conversation column, not the turn.
  • The bubble re-measures when its width changes, so a message can move between user-bubble and long text as the chat panel resizes.
  • Show More expands the message in place; Show Less collapses it back to 8 lines. Both are a normal button: Tab to reach it, Enter or Space to toggle.
  • Expanded is two-way bindable ([(expanded)]), so a host can keep the state across re-renders.
  • Copy, where offered, always copies the full message, not just the visible part.
 Place every bubble in a user turn so it sits on the right edge of the chat column. Stretch the bubble to the column width or left-align it. The alignment is what separates the recruiter’s turns from Amplify’s. Let long messages collapse, so the question and the start of Amplify’s reply stay on screen together. Truncate the message text itself or cut it with an ellipsis. The full message is always one click away.
