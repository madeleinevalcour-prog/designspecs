Data Table lists records in rows and columns. The header row stays fixed while the body scrolls, and every color, size and text style comes from the Tier-3 data-table tokens.

A table is a header row plus body rows. Each row starts with two fixed columns, then one cell per data column.

Column widthSet per column; otherwise grows to fit the text—
  • The table scrolls both ways inside its container. Give the container a max height and the header row stays pinned while the body scrolls.
  • Values stay on one line. A value longer than a fixed column width is cut off with an ellipsis.
  • The header checkbox selects every row, or clears them all. It shows as indeterminate when only some rows are selected.
  • The sort and filter icons are visual only. Sorting and filtering aren’t wired up yet.

A column can render any content instead of plain text. Engineering supplies a template for that column’s key; the table renders it in every row.
  • It’s a native <table> with <th scope="col"> headers, so screen readers announce the column for each cell.
  • Give each table an accessible name with the label input.
  • Row checkboxes are named “Select <first column value>”, for example “Select Sincere Jones”. The header checkbox is “Select all”.
  • The preview column header has a visually hidden “Preview” label.
