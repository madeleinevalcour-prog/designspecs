A Button with a count badge pinned to its top-right corner. In the Amplify header it’s the Chats toggle, and the count is the number of unread scheduled runs.
  • Frame: hugs the button and adds 4px above and to the right for the badge (button-with-count/spacing/badge-offset). No fill.
  • Button: Button, Theme=Secondary, Size=Small. Its label and state are set on the button.
  • Count badge: pinned to the top-right corner, so it grows to the left for 12 and 99+ and never pushes the button.
  • At 0 (or with show count off) the badge hides. The 4px space stays, so the button doesn’t move when a count appears.
  • Active = the Chats panel is open.
  • Clicking anywhere on the button toggles the panel; the badge isn’t a separate target.
  • Put the count in the button’s accessible name (“Chats, 2 new”). The badge is aria-hidden so it isn’t read twice.
  • Use aria-pressed for the open state, and aria-controls pointing at the panel.
