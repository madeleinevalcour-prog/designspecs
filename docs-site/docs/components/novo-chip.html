Novo Chip shows a short value, such as a tag, a filter or a status, with an optional leading glyph and an optional remove button. It’s styled from the chip/* tokens.

Hover applies when the chip is interactive (removable, or a link). Focus shows while its remove button or link has keyboard focus. Every color uses the same focus fill and a 2px stroke.

Warning has no visible stroke: Figma strokes it with its own fill token. Strokes are drawn inside the chip, so focus doesn’t change its size.
  • The remove control is a native button labelled “Remove <label>”. Enter or Space removes the chip.
  • With href, the label is a real link. Without it, a link-type chip is only styled as a link.
  • Glyphs are decorative and hidden from screen readers.

The component lives in the ats-ui Angular library. The app removes the chip in its (removed) handler.

<ats-novo-chip label="Java" removable (removed)="drop('Java')" /> <ats-novo-chip color="positive" icon="bolt" label="10 New Results" /> <ats-novo-chip type="link" href="/jobs/425" label="425 | Project Manager" />

Figma binds the warning stroke to chip/color/background/warning/*, although chip/color/border/warning/* tokens exist. The code follows Figma. Figma shows a hover state for every chip. The code applies it only to removable or linked chips, so a static chip doesn’t look clickable. The default-color link label is unbound in Figma (#296cc3, #1450a0 on hover and focus). The code uses chip/color/content/default/link and …/link-hover. Disabled tokens exist but Figma draws no disabled chip. The chip-group set (5666:132573) isn’t built yet.
