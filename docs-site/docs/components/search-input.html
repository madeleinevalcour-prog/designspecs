The search input is a single-line search field with a leading search icon. It comes in two shapes: the Fast Find field and the Menu’s Filter pill.
VariantUsed inShape
fieldFast Find, in the bowling alley32px tall, field/border/radius/default, 16px text (typography/bowling-alley/main-nav), close button on the right
pillThe Menu overlay’s Filter40px min height, fully round, 14px text (typography/input/value/default), no close button
  • The border follows the pointer and focus: default, hover, then focus (field/color/border/* for the field, search/color/border/* for the pill).
  • Clicking anywhere on the field focuses the text input.
  • The close button and Escape both emit closed; the owner decides what closing means (in Fast Find it ends the search).
  • It is a native input type="search", labelled by ariaLabel or, failing that, the placeholder.
  • The close button is labelled “Close search”.
