Checkbox selects or clears one item. It’s the 16×16 box used in the data table’s header and row cells, built on a native checkbox and styled from the checkbox/* tokens.
ValueWhat it meansWhat it looks like
UncheckedNot selectedWhite box, gray border
CheckedSelectedLight blue fill, dark blue border and check
IndeterminateSome, but not all, of a group is selectedLight blue fill, dark blue border and a short bar

Use indeterminate only on a box that controls a group, like the data table’s header. Clicking it selects the whole group.

Each value has four interaction states. Hover and focus change the border and fill; checked and indeterminate keep their own colors on hover.

Box: 16 × 16px Border: 1px (2px on focus) Radius: 2px Check: 10px Indeterminate bar: 8 × 2px
  • It’s a native <input type="checkbox">: Space toggles it, and forms and screen readers work without extra code.
  • The box has no visible label. Give it an aria-label (for example “Select row”), or wrap it in a <label> with text.
  • Indeterminate is the native property, so screen readers announce it as “mixed”.
  • Focus is shown by a thicker border, drawn inside the box, so it doesn’t shift layout.

The component lives in the ats-ui Angular library. It’s an attribute on a native <input> (the type is set for you), so checked, disabled, (change), ngModel and formControl work as usual.

<input ats-checkbox aria-label="Select row" [checked]="row.selected" (change)="toggle(row)" /> <input ats-checkbox aria-label="Select all" [checked]="all()" [indeterminate]="some()" (change)="toggleAll()" /> <label><input ats-checkbox [(ngModel)]="subscribed" /> Email updates</label>
