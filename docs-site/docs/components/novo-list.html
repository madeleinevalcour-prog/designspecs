Novo List stacks record rows: candidates, jobs, tasks, notes and submissions. Each row is a list item with an optional header and a content area, separated by a 1px divider.

Each preset is a list item already composed from the building blocks. Use the preset that matches the record type.

Default

An entity header (EntityIcon + title) over a fields row and an optional comment. Without fields, it shows company, contact, email and location.

Task

A circle-outline avatar and title over calendar, info and user fields, with an optional comment.

Note

A horizontal row: preview icon, date and time, then the note label and author over the note body.

Submission

A 12px circle in the job entity color and the job title over calendar, status and company fields.

Compose these inside a NovoListItem when no preset fits.

EntityIcon

The chip color comes from the entity token; the glyph is the entity icon in the knockout color.

  • NovoList has role="list" and each NovoListItem has role="listitem", so screen readers announce the item count.
  • All icons are decorative (aria-hidden); every field carries its meaning in its text.
  • Rows aren’t interactive yet. The title is link-colored but is not a link.

All parts are exported from ats-ui. Use a preset, or compose a NovoListItem from the building blocks. Project the header avatar with the avatar attribute.
