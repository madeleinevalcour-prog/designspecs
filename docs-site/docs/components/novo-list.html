Novo List stacks clickable record rows: candidates, contacts, jobs, tasks, notes and suggested actions. Each row is a list item with an optional header over a content area, separated by a 1px divider. The whole row is one click target.

Click anywhere on a row to activate it. Hover paints the row in the list hover background. Tab moves focus row by row; Enter or Space activates the focused row. Keyboard focus shows a 2px inset ring.

Try it: click a row, or Tab to one and press Enter or Space. The View button in the suggested action is a separate control and does not activate its row.

  • Rows are buttons by default. Set href to make a row a link instead.
  • Controls inside a row, such as a checkbox or Button, stay their own click targets.
  • Rows are not draggable and show no drag handle.
  • Set [clickable]="false" for a static row with no hover.

Each preset is a list item already composed from the parts. Use the one that matches the record.

Default

Entity chip and headline title over company, owner, phone, email, location and status, with an optional comment.

Note

No header. A preview icon, the date over the time, then owner, phone and note action over the note body.

Task

A circle-outline avatar and link text over date, status and owner.

Job

Link text with a circle in the job entity color, over company, date and status.

Fast-find

Like the default item without the owner field or a comment. The entity chip shows the record type.

Suggested action

A headline title over a status message and a small secondary Amplify View button.

Compose these inside a NovoListItem when no preset fits.

ItemAvatar

Header (14px icon), content (16px icon) or entity (24px chip in the entity color with a 12px white glyph). Entity covers candidate, contact, company, lead, opportunity, job, submission, placement, note and task.

ItemHeader

Standard: avatar, optional link text, headline title. Candidate-list: checkbox and avatar controls, link text with a subtle second title, and relevancy dots.

ItemField

Company, contact and candidate icons use their entity color; the rest use the illustration color. Caption is smaller and muted. Date-time stacks the date over the time.

  • NovoList has role="list" and each NovoListItem has role="listitem".
  • Each row has one native <button> (or <a> with href) laid over the row. It is a sibling of the row content, so no control is nested inside another.
  • The row action’s accessible name is the title. Note rows use the note action plus the date and time. Override it with label.
  • Icons are decorative (aria-hidden). Relevancy dots read as “Relevancy 3 of 5”.

All parts are exported from ats-ui. Use a preset, or compose a NovoListItem from the parts. Project the header avatar with the avatar attribute, candidate-list controls with controls, and an indicator chip with indicator.

Figma has no list-item focus variant. Rows use Button’s 2px inset ring in color/border/focus. The item header’s caption and “10 New Results” chip (novo-chip) aren’t built here; the header exposes an indicator slot for them. Figma’s suggested-action View button has a raw #008eff border. Code uses the Button component’s secondary Amplify styling instead (Figma also lists an Amplify gradient border style). Figma binds list/color/background/hover.
