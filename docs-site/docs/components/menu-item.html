A menu item is an app tile in the Menu: an icon container over a short label. The bowling alley’s Menu lays them out three to a row.
StateLook
defaultNo background
hovercolor/background/hover, and a 12px move handle (rotated 90°) on top. The top padding drops by the handle plus the gap, so the tile keeps its height
focusThe hover background with a 2px color/border/focus border, no handle
dragThe focus look plus the handle and the general/level 3 shadow
  • The icon is an icon container, size md (40px, 20px glyph). Apps that aren’t an entity use the neutral theme with their own glyph.
  • The label is one line in text style body/sm, centered, and truncates with an ellipsis.
  • Tiles are 96 to 128px wide (menu/spacing/menu-item/min-width, …/max-width).
  • Each tile is a native button; the label is its accessible name. The icon and the move handle are decorative.
  • Keyboard focus shows the focus state.
