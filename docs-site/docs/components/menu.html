The Menu is one component with three variants: the app Menu, the Add menu and the user menu. In the bowling alley they open from the Menu, Add and user tabs. Each is built from the Menu’s sub-components: Menu Header, Menu Item, Menu Option and Menu Edit.

Add and User share a dropdown card (padding menu/spacing/fastadd/*, dropdown/color/background/default, dropdown/color/border/default, dropdown/border/radius) with the bowling alley’s Help menu.
  • Filter. Typing in the header’s Filter narrows the Menu to apps whose name contains the text. In the Edit Menu it narrows the check lists; folders with no match are hidden. The Filter takes focus when the Menu or Edit Menu opens.
  • Add/Remove ↔ Done. Add/Remove swaps the Menu for the Edit Menu, in the same place. Done swaps back. Escape or a click outside closes either.
  • Check and uncheck. Checked apps show in the Menu. Unchecking an app hides it from the grid right away; checking it brings it back in its place. An app in two folders has one check, shown in both.
  • Grouped. With Grouped on, a folder shows in the Menu as its own section, labelled with the folder name in the section-header style (input/label/md, uppercase), below the main grid. With Grouped off, its apps are part of the main grid. Both folders start off, so the default Menu is one grid.
  • Reorder. Drag a tile onto another: it lands before the target (left half) or after it (right half). The dragged tile shows the Menu Item drag state, and a 2px color/border/focus bar in the gap marks where it will land. Keyboard: focus a tile and press Alt+Arrow Left/Right to move it one place, Alt+Arrow Up/Down to move it one row. Tiles move within their section.
  • Minimum height. The Menu is at least 520px tall (Figma 4266:86971), in both modes, so the card keeps its size when it swaps to the Edit Menu. Taller content scrolls inside the card. In the bowling alley the minimum gives way when the window is shorter.
  • Picking. Clicking an app tile, an Add row or a user row emits its label (preferences / logout for the user menu).
  • Order, checks and Grouped are kept while the page is open, not across page loads.
  • In the bowling alley each menu opens as a dialog named Menu, Edit Menu, Add or User menu.
  • App tiles, Add rows and user rows are native buttons; the label is the accessible name and the icons are decorative.
  • The Menu’s grid is a group per section. Alt+Arrow keys move the focused tile; the shortcut is in each tile’s description, and the new position is announced.
  • In the Edit Menu each folder is a section named by its title; apps are native checkboxes and Grouped is a native role="switch".
