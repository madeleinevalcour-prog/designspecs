Workflow Stepper shows where a candidate is in the placement pipeline: a row of steps in a rounded card, joined by connectors that fill the width, with the current step marked.

The candidate record places it at the top of the Overview, with the first step complete (a count of 3) and the second current.
  • Card — the container: background, 1px border, 16px radius, elevation 1.
  • Workflow item — one step: an indicator, the label on one line, and a connector that fills the space to the next step (at least 40px). The last step has no connector. Items share the width of the card.
  • Indicator — an 18px mark: an empty gray ring (upcoming), a blue ring (current), a filled blue circle with a check (complete), or a filled blue pill with a count such as 3 or 99+.
  • “current” label — a small blue label above the current step’s indicator.
  • Scroll arrows — appear on an edge only when there are more steps beyond it.
  • Workflow button — a separate tile with a count over a label, shown in a row above the stepper.

The stepper is built from three parts that can also be used on their own.

The steps scroll horizontally inside the card; the scrollbar is hidden. When steps run past an edge, a translucent arrow appears on that edge. Select it to scroll by three-quarters of the visible width (at least 160px). The left arrow appears once the row is scrolled.

The steps default to the seven placement stages. Pass your own labels for other workflows.
  • Steps are a list (role="list") named by ariaLabel, “Placement workflow” by default.
  • The current step has aria-current="step". Complete steps add visually hidden “(complete)” text.
  • Scroll arrows are native buttons labelled “Scroll workflow left / right”, reachable by keyboard when visible.
  • Connectors are decorative and hidden from screen readers.

The component lives in the ats-ui Angular library. Pass the steps as typed objects; each step’s status sets its look.

import { WorkflowStep, WorkflowStepper } from 'ats-ui'; steps: WorkflowStep[] = [ { label: 'Prescreen', status: 'complete', badge: '3' }, { label: 'Pre-Submission', status: 'current' }, { label: 'Internal Submission' }, { label: 'Placement' }, ]; <ats-workflow-stepper [steps]="steps" />
InputValuesDefault
stepsWorkflowStep[]: label, status (complete · current · upcoming), badge (count in the indicator pill)PLACEMENT_WORKFLOW_STEPS (7 steps, all upcoming)
ariaLabelAccessible name for the listPlacement workflow

A step with no status is upcoming. Mark at most one step current. A badge shows a count in the indicator of a complete or current step.

 The Figma stepper shows a count of 3 on the first step, but nothing says what the number represents. The arrow edge border (#f0f5f9), the arrow shadow and the 8px count-pill padding have no tokens yet.
