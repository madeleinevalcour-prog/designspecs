Workflow Stepper shows where a candidate is in the placement pipeline: a row of steps in a rounded card, joined by connectors, with the current step filled.

The prototypes place it at the top of the candidate record, with the first step current and a badge of 3.
  • Card — the container: background, 1px border, 16px radius, elevation 2.
  • Indicator — a 16px circle per step. Empty when upcoming, filled when current or complete.
  • Badge — optional short text inside the current step’s indicator.
  • Label — the step name, on one line.
  • Connector — a 40px line after every step but the last.
  • Scroll arrows — appear on an edge only when there are more steps beyond it.

The steps scroll horizontally inside the card; the scrollbar is hidden. When steps run past an edge, a translucent arrow appears on that edge. Select it to scroll by three-quarters of the visible width (at least 160px). The left arrow appears once the row is scrolled.

The steps default to the seven placement stages. Pass your own labels for other workflows.
  • Steps are an ordered list (<ol>) named by ariaLabel, “Placement workflow” by default.
  • The current step has aria-current="step". Complete steps add visually hidden “(complete)” text.
  • Scroll arrows are native buttons labelled “Scroll workflow left / right”, reachable by keyboard when visible.
  • Connectors are decorative and hidden from screen readers.

The component lives in the ats-ui Angular library. Pass the steps as typed objects; each step’s status sets its look.

import { WorkflowStep, WorkflowStepper } from 'ats-ui'; steps: WorkflowStep[] = [ { label: 'Prescreen', status: 'complete' }, { label: 'Pre-Submission', status: 'current', badge: '3' }, { label: 'Internal Submission' }, { label: 'Placement' }, ]; <ats-workflow-stepper [steps]="steps" />
InputValuesDefault
stepsWorkflowStep[]: label, status (complete · current · upcoming), badge (shown on the current step only)PLACEMENT_WORKFLOW_STEPS (7 steps, all upcoming)

A step with no status is upcoming. Mark at most one step current.

 The prototypes show “3” on the current step, but nothing says what the number represents. The prototype filled complete steps with color/text/link and called the state optional. The port uses the Figma token workflow/color/background/icon-complete, a slightly darker blue. Confirm the complete design, and whether complete steps take a glyph in workflow/color/content/complete. The prototype used color/border/subtle; the port uses workflow/color/border/icon-empty, which resolves to the darker color/border/default. The inactive connector (#d6d6d6), the arrow edge border (#f0f5f9), the arrow shadow, and the 11px badge text have no tokens yet. The current indicator and active connector borrow semantic tokens. The token set includes workflow/color/content/workflow-tooltip, but the prototype has no tooltip.
