A breadcrumb shows where you are inside a page area: a link back to the top level, a separator, then the page you’re on. It sits in the Amplify header next to the Amplify mark, and replaces the header tabs.

Figma’s state on breadcrumb:

  • Default: two levels. The root links back to the landing page; the current page or chat title follows the separator.
  • home: one level, on the landing page itself. “Amplify” is the current page, not a link.

Each level is a breadcrumb-link. Its state sets the color; all three use text style title/md (Inter Semi Bold 20/28).

  • Root: a link, color/text/subtle.
  • Hover: the root when hovered, color/text/link-hover.
  • Current: the page you’re on, color/text/headline. Not interactive.
  • Root: breadcrumb-link, state Root.
  • Separator: “/” in title/md, color/text/disabled. It isn’t interactive, so it uses the disabled color.
  • Current: breadcrumb-link, state Current.
  • Root, separator and current are 8px apart (breadcrumb/spacing/gap).
  • The root goes to the landing page. In the Amplify tab that’s a new chat (V1) or Home (V2).
  • On the landing page, use one level (state=home).
  • The current item is the page name (Scheduled, Meetings, Audits) or the open chat’s title.
  • When space runs out, only the current title truncates with an ellipsis. The root and separator never shrink.
  • Two levels only. A page reached from inside another (a prompt inside Scheduled) still shows “Amplify / [title]”.
  • Renders nav aria-label="Breadcrumb" around an ordered list.
  • The current item has aria-current="page". In the Amplify header it’s also the page’s h1 (headingCurrent).
  • The separator is aria-hidden.
  • The root is a real link (or a button when there’s no URL). Focus styling for links isn’t defined in Novo / Modern UI yet, so the browser’s default focus outline is kept until it is.
  • Root (#677079) and current (#2F2F33) pass 4.5:1 on white. The separator (#89909A) is about 3.3:1; it’s decorative and hidden from assistive tech.
