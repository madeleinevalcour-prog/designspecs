A checkbox with its label. Use it for one option in a list of independent choices, like the apps in the Edit Menu. Lay several out with a check list.

Figma’s Property 1 has nine values. Hover and focus are live; the rest follow the value and disabled.
  • Box: the 16px checkbox.
  • Label: text style input/value/default, filling the rest of the row.
  • Row: 8px between box and label (checkbox/spacing/gap-horizontal), 8px top and bottom (checkbox/spacing/padding-vertical).
  • Grip (has-gripper only): grip-vertical, 16px, before the box.
  • The row is a native label wrapping a native checkbox, so the text is its accessible name and clicking it toggles the box.
  • Space toggles the focused box. Indeterminate is announced as “mixed”.
