Icon draws one glyph from the Bullhorn icon set (321 icons). The glyph is a mask, so its color comes from a token, not from the file.

Browse and search the full set ↗

By default an icon uses color/icon/illustration. Pass any color token to change it. Inside a Button, icons take the button’s content color automatically, including every state and color variant.

Recolor icons with a raw hex or by editing the SVG. Bind a token so grayscale modes and theme changes flow through.

Icons are square. The default is 16px; Button sizes them to 12, 14 and 16px to match its small, default and large sizes.
  • Icons are decorative and hidden from screen readers.
  • When an icon is the only content of a control, give the control the accessible name, for example aria-label="Close" on an icon Button.
