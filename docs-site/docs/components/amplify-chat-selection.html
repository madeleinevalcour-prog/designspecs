The bar that appears under a chat table or card stack once records are selected: the selection count on the left and a split button on the right that names the action and the count. The table and the card stack use the same bar, so selection works the same in both.

The rules are in Chat interface patterns, Selection and bulk actions. That page wins over the earlier record actions study where they differ: the label is Title case and the bar is hidden at zero.

Two primary small Buttons 1px apart, rounded on the outer sides only. The left segment runs the default action; the chevron opens a menu of related actions.

  • The label is verb + count + noun, Title case: “Add 5 Contacts”. It follows the selection live; the noun is singular for 1.
  • With nothing selected the button is hidden, and so is the bar.
  • No check icon on the button. Nothing has happened yet.

The menu is the ATS Dropdown (dropdown, optgroup, option), right-aligned under the chevron, the same component as other ATS dropdowns. Hold about 2–4 related actions, each verb first. With no actions the chevron is disabled.

Show checkboxes and the bar only when the reply offers a bulk action. Keep an empty bar or a disabled “Select contacts to add” button on screen at zero. Name the verb and the count in Title case: “Add 5 Contacts”. Use a single button with a chevron, or add a check icon to the button. Mark higher-risk menu actions as preview, so they say “Review first” and open a review before running. Write to Bullhorn when records are selected, or put the action on the follow-up row. Use a split button when one action is clearly the default and there are about 2–4 others. Build a custom menu. Use the ATS Dropdown.

The selection parts have no Amplify component tokens. The bar uses the Data Table pagination tokens; the split button uses the primary small Button and the Dropdown.

  • The bar is a region named “Selection”. Its count is aria-live="polite", so changes are announced.
  • The split button is a role="group". The chevron is a menu button (aria-haspopup, aria-expanded) named “More actions for N selected”.
  • The menu is role="menu" with menu items; the “Review first” hint is part of the item’s name.
  • The pager is a nav named “Pages, page X of Y”; page buttons are named “Page N” and the current one has aria-current="page". Previous and next are disabled at the ends.
  • The bar is removed with hidden at zero, so screen readers don’t reach an empty bar.
