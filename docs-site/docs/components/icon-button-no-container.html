A small icon-only button with no resting container. It shows a 12px glyph in a 24×24 hit area and only fills in on hover and press.

Five states. The glyph color holds steady from default to active; only the background and focus ring change, so the button never shifts layout.

The glyph comes from the icon set and defaults to chevron-down. Pass the icon the design specifies; it takes the button’s content color.

 Size: 24 × 24px Padding: 4px Radius: 4px Glyph: 12px Focus ring: 2px, inset
  • It’s a native <button>, so keyboard, forms and screen readers work without extra code.
  • There’s no visible text: always give it an aria-label that names the action.
  • The focus ring is drawn inside the edge, so it’s visible without shifting layout.

The component lives in the ats-ui Angular library. It’s an attribute on a native <button>, so disabled, type and (click) work as usual.

<button ats-icon-button-no-container aria-label="Expand"></button> <button ats-icon-button-no-container icon="close" aria-label="Remove filter"></button>

There are no no-container color tokens, so colors use the icon-button tokens (button/color/icon/*), including the darker glyph on hover, focus and press. The resting and disabled backgrounds stay transparent (the icon-button token is white), since this variant has no container.
