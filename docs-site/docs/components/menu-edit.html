The Edit Menu lets people choose which apps the bowling alley’s Menu shows. It opens from the Menu’s Add/Remove button and goes back to the Menu with Done.
  1. Header: a menu header in edit mode: title “Edit Menu”, a success Done button, and the Filter.
  2. Folder: one per app group (“Primary”, “Pay & Bill”).
  3. Folder title: the folder name in text style body/lg, and a switch labelled “Grouped”.
  4. Folder items: the folder’s apps as checkbox + label rows, two per inline check list.
  • Add/Remove in the Menu header swaps the Menu for the Edit Menu, in the same place. Done swaps back. Escape or a click outside closes either.
  • Checked apps show in the Menu. Unchecking an app hides it from the Menu grid right away; checking it brings it back in its place.
  • An app in two folders has one check, shown in both.
  • Grouped on: the folder’s apps also appear in the Menu as their own section, labelled with the folder name (the Menu’s section-header style). Grouped off: the folder’s apps are part of the main grid.
  • Filter narrows the check lists to apps whose name contains the text. Folders with no match are hidden.
  • The Filter takes focus when the Edit Menu opens.

The folders map Figma’s check lists onto the Menu’s 18 apps.

  • Primary: Placements, Submissions, Candidates, Opportunities, Companies, Contacts, My Dashboard, Jobs, Analytics, Change Requests (named in Figma, in Figma’s order), then the other Menu apps in Figma’s “checked” placeholder slots. Grouped off.
  • Pay & Bill: Placements, Submissions, Candidates, Opportunities, as in Figma. Grouped starts off for both folders, so the default Menu is the single app grid of the live product (Figma draws Pay & Bill switched on).
  • The overlay is a dialog named “Edit Menu”. Each folder is a section named by its title.
  • Every app is a native checkbox with its name as the label; each Grouped switch is a native role="switch".
  • Tab moves through Done, the Filter, then each folder’s switch and checkboxes in order.
