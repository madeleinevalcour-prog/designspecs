A switch turns one setting on or off and applies it right away. The Edit Menu uses it for each folder’s “Grouped” setting, and the Help menu for “Show Chat Button”.

Figma’s status × has-label: off, on, disabled-off and disabled-on, each with or without a label. The label sits left of the track.
  • Track: 32px wide pill, 2px padding (spacing/padding/xxsm). Off has a 1px border; on is filled.
  • Thumb: 16px circle with a 1px border and the general/level 1 shadow. It sits left when off, right when on.
  • Label (optional): text style body/sm, 8px from the track (switch/spacing/gap).
  • It renders a native checkbox with role="switch", so it’s announced as a switch with its on/off state. Space toggles it.
  • The whole row is a label: clicking the text toggles it. Without a visible label, give it an aria-label.
  • Keyboard focus shows a 2px color/border/focus ring around the track.
