  • It’s decorative: the glyph is hidden from screen readers. Put the meaning in the text beside it (the record title or app name), or label the control that contains it.
  • The glyph is white (icon-container/icon) on every fill. Check contrast on the light fills (contact, submission) before using the container without a text label.

The component lives in the ats-ui Angular library and wraps an <ats-icon>.

<ats-icon-container theme="candidate" /> <ats-icon-container theme="amplify" size="md" /> <ats-icon-container theme="neutral" size="md" icon="dashboard" /> <ats-icon-container size="md" icon="task" background="var(--color-entity-task)" />

Figma has no task theme. The bowling alley Menu paints Tasks with color/entity/task through background, while Figma’s Add menu shows Task as neutral. Confirm which is right, or add a task theme. Every Figma variant shows the Candidate glyph as a placeholder. The code defaults each theme to its own entity glyph instead. The gradient is a Figma style, not a variable. The code reuses the stops used by the other Amplify surfaces in ats-ui.
