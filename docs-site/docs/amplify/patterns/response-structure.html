Every reply follows the same top-to-bottom order, so replies are predictable to scan and the answer always comes first (NN/g truncated pyramid; Gestalt continuity).

  1. User message. amplify-chat/user-bubble, right-aligned. Always
  2. Identity. Amplify icon and name. Always
  3. Answer. One sentence stating the result, with records as inline entity links. Always
  4. Section heading. Only when the reply has 3 or more parts to scan between. Optional
  5. Evidence. A data table, cards or a list. Optional
  6. Selection bar. Selected count and the bulk action. Only when rows or cards are selected. Optional
  7. Sources row. When the answer uses records. Optional
  8. Follow-up chips. 2–3 next steps instead of "Want me to…?" in prose. Optional
  9. Message controls. Copy, thumbs up, thumbs down, Save prompt. Thumbs and Save prompt are toggles: the bookmark is filled once the prompt is saved. Always
  • Also optional: a rationale line under the evidence (how it was ranked or filtered), and a draft block or literal value block.
  • While generating, a status line names the current step ("Searching open jobs…"); the Stop control is in the chat input, next to Send. Memory changes show as a status line with View and Undo.
  • Never in a reply: filler openers, feedback requests in prose, more than 3 clarifying questions, numbered headings, or a retry control.
  • The smallest reply is identity, a one-sentence answer and the controls (Rams 10).
