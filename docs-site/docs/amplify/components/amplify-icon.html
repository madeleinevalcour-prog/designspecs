The Amplify icon marks a feature, action or piece of content as Amplify-powered. It works with the Amplify gradient: the gradient is never the only signal.

Use the Amplify icon only on Amplify-powered features. Use the filled icon by default, and the line icon for unselected or disabled states or when less emphasis is needed. Use it as a generic “magic”, “new” or decorative icon. Signal Amplify with color alone. Pair the treatment with a label, icon, or established Amplify entry point so the meaning is not carried by the gradient by itself.
  • The icon is decorative and hidden from screen readers (aria-hidden). Next to a text label such as “Amplify” or “Relevance Signals”, the label carries the meaning.
  • When the icon is the only content of a control, give the control the accessible name, for example aria-label="Amplify".
 The Icon/Amplify Radial fill has no token. Each component that uses it repeats the gradient stops in its own CSS. See Amplify → Color → Token gaps.
