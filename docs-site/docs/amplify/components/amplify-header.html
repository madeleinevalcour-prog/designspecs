The one-row header for the full-page Amplify tab, used by the full-page chat. It replaces the title row and tabs of the old full-page chat header; Amplify pages are reached from the Amplify menu in the bowling alley instead.

Containernovo-header-amplifyHeader surface, 1px bottom border, general/level 2 shadow. 16px top and bottom, 32px left and right; 72px tall.
Amplify markIcon Container · md · amplifyIdentifies the Amplify tab. Decorative.
BreadcrumbBreadcrumb“Amplify / page or chat title”. On the landing page only “Amplify”.
ChatsButton with countOpens and closes the Chats panel. The count is unread scheduled runs.
CloseButton · Icon · DefaultCloses the Amplify tab. Optional.
  • The breadcrumb root goes to the Amplify landing page: a new chat in V1, Home in V2. On the landing page it’s the current item, not a link.
  • The current item is the page name (Scheduled, Meetings, Audits) or the open chat’s title, and updates if the chat is renamed.
  • Chats opens and closes the Chats panel; Active = panel open. The panel’s close returns focus to Chats.
  • The count is the total of unread scheduled runs and drops as each scheduled chat is opened. At 0 the badge hides.
  • Only the current title truncates; the mark, root and actions keep their size.
  • The breadcrumb is a nav labelled “Breadcrumb”; the current item is the page’s h1 with aria-current="page".
  • The Amplify mark is aria-hidden.
  • Chats has aria-pressed for the open state and aria-controls for the panel (chatsPanelId). Its name includes the count (“Chats, 2 new”); the badge is hidden from screen readers.
  • Close is named “Close Amplify”.
