Saved prompts the recruiter can send to Amplify in one click. It opens from Prompt Library in the chat input and sits next to the composer: Bullhorn’s default prompts, prompts the recruiter made, and the ones they starred.

A list-item card (padding 8 / 16, radius 8). The header row holds the prompt’s icon (14px, no container), the title, then the star and kebab grouped on the right. Below it: the record type the prompt runs on, the scheduled time, the tag icon with one chip per tag, and the description.

  • The header icon is chosen when the prompt is made, or by Amplify when it generates one. Bullhorn’s default prompts each have their own.
  • The schedule shows the time a scheduled prompt runs. It’s hidden on prompts that aren’t scheduled.
  • Tags categorize prompts. A prompt can have several, so they use a chip group after the tag icon.

850 wide, so it reads as distinctly different from the starting-point composer (750) and the active-chat input (800). Card border and radius 16, general/level 4. The tab bar (48 tall) holds Favorites, My Prompts and All Prompts, then the search input and the category filter. The grid is two columns of prompt cards, 16 apart with 16 padding. Every row is as tall as the tallest card in the grid, so the grid stays even while each card’s data row can wrap; content sits at the top of the card and extra space falls at the bottom.

  • The active tab and the filter icon use the page’s entity color. On Amplify that’s button/color/secondary-amplify/content/default. Favorites shows a filled star while it’s active.
  • The search input and category filter match the ones used elsewhere in the ATS (candidate list, search).

Built from the empty-state parts (64px icon, title/sm heading, body/default text, optional Secondary button), centered in the grid with 48 above and below.

The library always sits 8px from the composer, centered on it, so it reads as part of the composer (Gestalt connectedness and common region).
