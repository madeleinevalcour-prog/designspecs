Bullhorn Amplify is Bullhorn’s AI product for recruitment and staffing agencies. Its core promise: more placements, more profit, same team. It runs high-volume, repetitive recruiting tasks autonomously (sourcing, screening, outreach, enrichment) so recruiters can focus on the relationship work only humans can do.

Amplify is not a standalone app. It works inside Bullhorn (the Bullhorn Platform and Bullhorn Recruitment Cloud), on the data already in a firm’s system of record. That matters for design: we’re building within an existing workflow and data model, not on a blank canvas.

Two product layers

LayerWhat it is
Digital WorkersAI-powered team members that run Skills: specific task types like screening, matching, outreach or data enrichment. They run 24/7, handle volume, and surface output back into Bullhorn. Bought as a package and billed by Activity (a single completed AI task).
Amplify ChatA conversational interface built on a staffing-specific LLM. Recruiters ask natural-language questions, surface insights from their data, and take actions without leaving Bullhorn. Secure (data stays in Bullhorn, not sent to public AI tools), staffing-literate out of the box, and able to act, not just answer.

What makes Amplify different from general AI tools

Amplify is purpose-built for staffing. It understands job orders, candidate profiles, client relationships and the recruiting lifecycle without configuration. It reads the same data the recruiter is already working with. And it’s secure by design: candidate and client data never leave the Bullhorn environment.

Users

UserWhat they do with Amplify
RecruitersThe primary end users. Day to day they kick off screens, review match results, send outreach, generate candidate presentations, and ask Amplify Chat questions mid-workflow. Their goal is speed and quality: faster placements, better candidates, less manual work. They are often overwhelmed and context-switching constantly.

Capabilities

Each Digital Worker bundles a set of Skills.

Beyond Skills, every record in Bullhorn has Amplify Assistant: inline AI that offers content generation, recommendations and quick actions in context. It does not count against Activity allowances.

How Amplify works

Understanding how output is generated and why it varies lets us design UIs that set the right expectations and help users get the best results.

What Amplify reads. Amplify reads Bullhorn records based on the Skill in use and the user’s existing permissions. It cannot access data the user doesn’t already have permission to see. The data available varies by Skill: Amplify Assistant reads only the open record; Amplify Chat can search the user’s full data set, including Analytics; Screen reads the job order and submission data. Output quality is tied directly to data quality. Thin records produce thin output, so empty and insufficient-data states are real and common.

How output is generated. Amplify uses a large language model to interpret the data in a record and produce a response. Output is controlled by prompts: instructions that set tone, format, what to include and what to exclude. Admins can customize prompts in Prompt Studio for any Skill. Prompts are the primary lever for output quality. If output doesn’t match expectations, look at the prompt first, not the data. Design should make this legible to users.

Why output varies. Amplify won’t give exactly the same output on the same record twice. That isn’t a bug: the model words and frames things slightly differently each run. Output that’s consistently off is a signal to investigate (prompt first, then data quality); output that’s just worded differently is working as intended. So we don’t imply exact repeatability, and we design review moments that help users evaluate output rather than assume it’s correct.

The gradient is a meaning cue, not decoration

Use the Amplify color treatment to indicate where an action, content or any other UI element is related to Amplify or AI. Wherever it appears, it marks that surface or control as Amplify. Don’t use it for anything else.

Source: Amplify → Color

The Amplify gradient marks AI-assisted features

Meaning is encoded consistently. A signal means the same thing wherever it appears, and the Amplify gradient marks AI-assisted features. Once a user learns a cue, it holds across the product.

Source: Principles

Adding Amplify must not take away existing controls

When AI is layered into an established workflow, it should only add control, never remove it. An AI feature shouldn’t reduce what a user can already do. Opening Amplify Chat, for example, should not make expected record controls elsewhere in the interface unavailable or harder to reach.

Source: AI interaction guidelines → 2. AI assists — it does not replace judgment

The right pane is Amplify-first space

Treat the right pane as shared, Amplify-first space. It is often claimed by Amplify (the universal chat panel that narrows the page, or AI-assisted form-fill controls docked to the right) or by a functional tool the form needs. Design pages to reflow to the narrowed width these create.

Source: Form pages — design decisions → Proposed changes

Amplify output carries the Amplify identity

Show where output came from. Every Amplify reply, suggestion or generated value carries the Amplify identity (the icon and the name “Amplify”), so users can tell AI output apart from their own data.

The Amplify icon marks a feature, action or piece of content as Amplify-powered. It works with the gradient: don’t signal Amplify with color alone. Pair the treatment with a label, icon or established Amplify entry point so the gradient isn’t carrying the meaning by itself (Amplify → Color).
