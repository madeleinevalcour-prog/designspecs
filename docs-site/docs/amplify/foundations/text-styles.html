use body/default (14/20) for all reading text. It matches the density of the rest of Bullhorn. use title/default or title/md in a response. Those sizes belong to the app chrome. use italics, ALL CAPS, underline, or colored text for emphasis. Emphasis comes from weight (Modern UI: never signal state with color alone). Use input/label/* only in table headers, through novo-data-table.

Headings

  • Default to no headings. Use ## only when a reply has 3 or more parts the recruiter will scan between.
  • One heading level per reply. Headings are 2–5 words in title case, with no numbering and no trailing punctuation.
  • Never open with a heading. The first line is the answer.

Lists

  • Use a numbered list only when order means something (rank, priority, steps). Use bullets for everything else.
  • One idea per item, at most one level of nesting, and each list starts at 1.
  • Avoid runs of very short fragments. Merge them into a sentence or a table row.

Emphasis

  • At most one bold phrase per paragraph or item, and only for the fact the recruiter acts on.
  • Don't use bold as a heading or bold labels and values in the same line.
