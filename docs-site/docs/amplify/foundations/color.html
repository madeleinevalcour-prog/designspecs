Amplify has a dedicated color treatment — a green-through-blue radial for fills and a matching gradient for borders. Use it to indicate where an action, content, or any other UI element is related to Amplify or AI. It is a meaning cue, not decoration: wherever it appears, it marks that surface or control as Amplify. Do not use it for anything else.

Both are delivered as named paint styles, not variables — Figma cannot store a gradient in a variable, so this treatment sits outside the primitive → semantic structure that governs the rest of color. Apply the named style directly; there is nothing to bind to, and any change is a direct edit to the paint style. Exact stops are defined in Subatomic → color / amplify ↗.

Match the form to the element: the buttons/backgrounds radial for button fills and container backgrounds, the icon radial for icons, and the gradient for borders — the two radials are not interchangeable. Apply the named paint style, and use the state variants (hover, disabled) that ship with it. Reach for the translucent background when an Amplify surface needs emphasis over the default background — for example an inline Amplify alert — rather than a full-strength fill behind reading content. Rebuild the gradient by hand, approximate the stops, or apply it to anything unrelated to Amplify — that dilutes what it signals. Don't pair the radial fill with body text sitting directly on it; keep it behind chrome, controls, or short labels where contrast holds. Signal Amplify with color alone. Pair the treatment with a label, icon, or established Amplify entry point so the meaning is not carried by the gradient by itself. None of the Amplify gradients or tints has a token yet.
